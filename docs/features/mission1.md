# Mission 1 — 게임 난이도 및 규칙

## 개요

| 항목 | 내용 |
|------|------|
| 배경 | 일본 후지산 (Mt. Fuji) |
| 스테이지 수 | 3개 (1-1 / 1-2 / 1-3) |
| 성격 | 입문 구간 — 조작법과 분열 패턴 학습 |
| 제공 무기 | 와이어 (기본) |

---

## 스테이지별 구성

### 1-1 (입문)

| 항목 | 내용 |
|------|------|
| 풍선 구성 | 대형(Large) 풍선 2개 |
| 제한 시간 | 60초 |
| 플랫폼 | 없음 (평지) |
| 난이도 | ★☆☆☆☆ |

- 풍선 수가 적고 이동 속도가 느려 기본 발사 조작에 집중 가능
- 대형 풍선을 터뜨리면 중형 2개로 분열 → 총 최대 8개의 극소 풍선 처리

---

### 1-2 (기초)

| 항목 | 내용 |
|------|------|
| 풍선 구성 | 대형 1개 + 중형 2개 |
| 제한 시간 | 60초 |
| 플랫폼 | 낮은 발판 1~2개 |
| 난이도 | ★★☆☆☆ |

- 크기가 다른 풍선이 동시에 등장해 처리 순서를 고려해야 함
- 낮은 발판으로 인해 일부 풍선의 이동 경로가 변화
- 작은 풍선이 발판 위에서 짧게 튀는 패턴 등장

---

### 1-3 (마무리)

| 항목 | 내용 |
|------|------|
| 풍선 구성 | 대형 2개 + 중형 1개 + 소형 2개 |
| 제한 시간 | 55초 |
| 플랫폼 | 발판 2~3개 (높이 차이 있음) |
| 난이도 | ★★★☆☆ |

- 풍선 수가 많아 처리 우선순위 판단 필요
- 분열 후 여러 크기의 풍선이 겹치는 상황 발생
- Mission 1 최종 스테이지로, 이후 미션의 패턴에 대비한 연습 구간

---

## Mission 1 공통 규칙

### 난이도 파라미터

| 파라미터 | 값 |
|----------|----|
| 풍선 이동 속도 | 느림 (기준 속도의 80%) |
| 풍선 반동 높이 | 낮음 |
| 아이템 출현 빈도 | 높음 |
| 제한 시간 | 55~60초 |
| 초기 잔기 | 3개 |

### 등장 아이템
- 시계, 배리어, 1UP 위주로 등장
- 다이나마이트는 Mission 1에서 미등장

### 클리어 조건
- 1-1 → 1-2 → 1-3 순서로 모든 스테이지 클리어
- 스테이지 도중 게임오버 시 해당 스테이지 처음부터 재시작 (미션 처음으로 돌아가지 않음)

---

## 학습 목표 (UX 설계 관점)

Mission 1은 플레이어가 다음 개념을 자연스럽게 익히도록 난이도를 배치한다.

1. **1-1** — 와이어 발사 타이밍과 풍선 분열 이해
2. **1-2** — 크기 혼합 풍선의 처리 우선순위 판단
3. **1-3** — 다수의 풍선을 동시에 관리하는 공간 활용 연습
