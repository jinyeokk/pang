# 게임 룰 상세

## 기본 목표

각 스테이지에 등장하는 **모든 풍선을 제한 시간 내에 제거**하면 클리어.  
풍선에 닿거나 제한 시간이 초과되면 1미스 처리된다.

---

## 플레이어

### 이동
- 좌우 방향키로만 이동 (점프 불가)
- 화면 양 끝에서 반대편으로 이동 불가 (벽에 막힘)

### 공격
- 발사 키(Space)로 무기 발사
- 와이어 계열은 천장까지 닿는 줄을 생성하며 줄에 풍선이 닿으면 터짐
- 줄이 천장에 닿거나 풍선에 맞으면 사라짐
- 한 화면에 동시에 발사 가능한 줄 수는 무기마다 다름

### 사망 조건
- 풍선(원본 또는 분열된 것)에 몸이 닿으면 즉시 1미스
- 배리어 보유 중이면 1회 무적 처리 후 배리어 소멸

---

## 풍선(버블)

### 크기 및 분열 구조

| 단계 | 크기 | 분열 후 |
|------|------|---------|
| 1단계 | 대(Large) | 중(Medium) × 2 |
| 2단계 | 중(Medium) | 소(Small) × 2 |
| 3단계 | 소(Small) | 극소(Tiny) × 2 |
| 4단계 | 극소(Tiny) | 소멸 |

- 분열 시 맞은 위치에서 좌우로 나뉘어 튀어오름
- 크기가 작아질수록 바닥 반동 높이가 낮아져 회피 난이도 상승

### 이동 패턴
- 풍선은 포물선 궤도로 이동하며 바닥·벽에서 반사
- 중력의 영향을 받아 바닥에서 튀어 오름
- 크기별로 이동 속도와 반동 높이가 다름

## 무기

| 무기명 | 발사 방식 | 특징 |
|--------|-----------|------|
| 와이어 (기본) | 천장까지 줄 생성 | 동시 1줄 유지 가능 |
| 더블 와이어 | 천장까지 줄 생성 | 동시 2줄 유지 가능, 범용성 최고 |
| 파워 와이어 | 천장에서 좌우로 퍼짐 | 낮게 튀는 풍선 제압에 유리 |
| 벌칸 미사일 | 탄환 형태 발사 | 줄 없음, 빠르지만 판정 짧음 |

- 무기 아이템을 획득하면 즉시 교체됨
- 스테이지 클리어 후 무기 유지

## 아이템

| 아이템 | 효과 | 비고 |
|--------|------|------|
| 시계 | 풍선 일시정지 | 제한 시간은 계속 흐름 |
| 모래시계 | 풍선 이동속도 감소 | 효과 시간 제한 있음 |
| 배리어 | 풍선 충돌 1회 무적 + 풍선 제거 | 중첩 불가 |
| 다이나마이트 | 모든 풍선을 즉시 최소 크기로 분열 | 위험 아이템 |
| 1UP | 잔기 1개 추가 | |

- 아이템은 풍선을 터뜨릴 때 확률로 등장
- 아이템은 일정 시간 후 사라짐

## 점수 시스템

| 행동 | 점수 |
|------|------|
| 극소 풍선 제거 | 100점 |
| 소 풍선 제거 | 200점 |
| 중 풍선 제거 | 300점 |
| 대 풍선 제거 | 500점 |
| 스테이지 클리어 보너스 | 남은 시간 × 10점 |

---

## 스테이지 진행

### 제한 시간
- 스테이지마다 제한 시간이 주어짐 (초 단위 카운트다운)
- 시간 초과 시 1미스 처리 후 동일 스테이지 재시작

### 미스 처리
- 미스 발생 시 잔기 1개 감소
- 동일 스테이지를 처음부터 재시작 (풍선 초기화)

### 게임오버
- 잔기가 모두 소진되면 게임오버
- 게임오버 후 메인 화면으로 복귀

### 스테이지 클리어
- 모든 풍선 제거 시 클리어 연출 후 다음 스테이지로 이동
- 클리어 보너스 점수 지급 후 전환
