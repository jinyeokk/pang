# 메인 화면 구성

## 개요

게임 실행 시 처음으로 표시되는 화면이다.  
플레이어가 게임을 시작하거나 옵션을 선택할 수 있는 진입점 역할을 한다.

---

## 화면 레이아웃

```
┌──────────────────────────────────────────┐
│                                          │
│   ●        ○          ●        ○         │  ← 장식 버블 (배경 애니메이션)
│                                          │
│                  PANG                    │  ← 타이틀 (네온 컬러 순환)
│           © 1989 MITCHELL CORP           │  ← 서브타이틀
│                                          │
│                                          │
│           ▶  GAME START                  │  ← 선택된 항목 (골드 강조)
│              HIGH SCORE                  │
│              GAME QUIT                   │
│                                          │
│                                          │
│         PRESS ENTER TO SELECT            │  ← 안내 문구 (깜빡임)
│                                          │
│   ○                      ●              │  ← 장식 버블 (배경 애니메이션)
└──────────────────────────────────────────┘
```

---

## 구성 요소

### 타이틀
- 게임 이름 "PANG"을 화면 상단 중앙에 크게 표시
- 3초 주기로 핑크 → 노랑 → 시안 → 연두 순으로 네온 컬러 순환
- 글로우(text-shadow) 효과 적용

### 배경 장식
- 반투명 컬러 버블 6개가 화면 하단에서 상단으로 떠오르는 루프 애니메이션
- 버블마다 크기·색상·속도·딜레이가 달라 자연스러운 느낌 연출
- 게임 풍선을 연상시키는 시각적 힌트 역할

### 메뉴 항목

| 항목 | 동작 |
|------|------|
| GAME START | 게임 화면으로 전환 (Mission 1-1 시작) |
| HIGH SCORE | "준비 중" 안내 문구 표시 (Phase 6에서 구현) |
| GAME QUIT | "브라우저 탭을 닫아 종료해주세요" 안내 표시 |

### 선택 항목 강조
- 선택된 항목: 골드(`#FFD700`) 텍스트 + 글로우 + 연한 배경 + 테두리
- 비선택 항목: 연보라(`#aaaadd`) 텍스트
- 선택된 항목 왼쪽에 `▶` 커서 표시

### 안내 문구
- "PRESS ENTER TO SELECT" 를 1초 간격으로 깜빡임 처리

## 키보드 조작

메인 화면에서 사용할 수 있는 키 입력은 다음과 같다.

| 키 | 동작 |
|----|------|
| `↑` (ArrowUp) | 메뉴 커서를 위로 이동. 첫 번째 항목에서 누르면 마지막 항목으로 순환 |
| `↓` (ArrowDown) | 메뉴 커서를 아래로 이동. 마지막 항목에서 누르면 첫 번째 항목으로 순환 |
| `Enter` | 현재 선택된 메뉴 항목 실행 |

### 커서 순환 동작 예시

```
현재: GAME START (index 0)
  ↑ 입력 → GAME QUIT (index 2)   ← 처음에서 끝으로 순환
  ↓ 입력 → HIGH SCORE (index 1)

현재: GAME QUIT (index 2)
  ↓ 입력 → GAME START (index 0)  ← 끝에서 처음으로 순환
  ↑ 입력 → HIGH SCORE (index 1)
```

### 마우스 클릭
- 메뉴 항목을 직접 클릭해도 동일하게 동작한다
- 클릭 시 해당 항목으로 커서가 이동한 뒤 즉시 실행

## 화면 전환

```
앱 시작
  │
  ▼
메인 화면 (screen = 'main')
  │
  ├─ GAME START 선택 (Enter / 클릭)
  │       │
  │       ▼
  │   게임 화면 (screen = 'game')
  │
  ├─ HIGH SCORE 선택 → "준비 중" 안내 (현재 화면 유지)
  │
  └─ GAME QUIT 선택  → "탭을 닫아주세요" 안내 (현재 화면 유지)
```

---

## 구현 시 유의사항

- `keydown` 이벤트 리스너는 메인 화면 마운트 시 등록, 언마운트 시 반드시 제거한다
- 메뉴 커서 상태(`selectedIndex`)는 `MainMenu` 컴포넌트 내부에서 관리한다
- 화면 전환 상태(`screen`)는 `App` 최상위에서 관리한다
- `GAME QUIT`은 브라우저 보안 정책상 `window.close()` 강제 종료가 불가하므로 안내 문구로 대체한다
