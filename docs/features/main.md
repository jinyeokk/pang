# 메인 화면 구성

## 개요

게임 실행 시 처음으로 표시되는 화면이다.  
플레이어가 게임을 시작하거나 옵션을 선택할 수 있는 진입점 역할을 한다.

---

## 화면 레이아웃

```
┌─────────────────────────────────┐
│                                 │
│           PANG                  │  ← 게임 타이틀 (상단 중앙)
│                                 │
│        [ GAME START ]           │  ← 1인 플레이 시작
│                                 │
│        [ HIGH SCORE ]           │  ← 최고 점수 확인
│                                 │
│  ┌──────────────────────────┐   │
│  │  HIGH SCORE :  000000    │   │  ← 현재 최고 기록 표시
│  └──────────────────────────┘   │
│                                 │
│       PRESS ENTER TO START      │  ← 시작 안내 문구 (깜빡임)
│                                 │
└─────────────────────────────────┘
```

---

## 구성 요소

### 타이틀
- 게임 이름 "PANG" 을 화면 상단 중앙에 표시
- 레트로 아케이드 스타일 폰트 사용

### 메뉴 항목
| 항목 | 동작 |
|------|------|
| GAME START | 미션 1 스테이지 1-1 부터 게임 시작 |
| HIGH SCORE | 상위 점수 목록 화면으로 이동 |

### 최고 점수 표시
- 현재까지 기록된 최고 점수를 화면 하단에 상시 표시
- 초기값은 `000000`

### 시작 안내
- "PRESS ENTER TO START" 문구를 일정 간격으로 깜빡임 처리
- Enter 키 또는 메뉴 선택으로 게임 시작

---

## 화면 전환

```
메인 화면
    │
    ├─ GAME START 선택 → 게임 화면 (Mission 1-1)
    │
    └─ HIGH SCORE 선택 → 점수 화면
```

---

## 구현 시 고려사항

- 메뉴 선택은 키보드 방향키 (↑ / ↓) 로 이동, Enter 로 확인
- 선택된 메뉴 항목은 색상 또는 커서(▶)로 강조 표시
- 배경은 단색 또는 간단한 패턴으로 구성 (애니메이션 풍선 연출 가능)
