# 개발 계획 — Phase별 목표

> 각 Phase는 **독립적으로 실행 가능한 소프트웨어** 상태로 마무리됩니다.  
> 고객님께서 직접 브라우저에서 플레이해보신 뒤 피드백을 주시면 다음 Phase로 진행합니다.

---

## Phase 1 — 메인 화면

**목표:** 게임을 켰을 때 가장 처음 보이는 화면 완성

### 구현 내용
- 게임 타이틀 "PANG" 표시
- 메뉴 항목 3개: `GAME START` / `HIGH SCORE` / `GAME QUIT`
- 키보드(↑ ↓ Enter)로 메뉴 이동 및 선택
- 선택된 항목 강조 표시 (색상 또는 ▶ 커서)
- `GAME QUIT` 선택 시 종료 안내 문구 표시 (브라우저 특성상 탭 닫기 유도)
- `GAME START` 선택 시 게임 화면으로 전환 (Phase 2에서 구현)

### 고객님 확인 포인트
- [ ] 타이틀과 메뉴가 보기 좋게 배치되어 있는가
- [ ] 키보드로 메뉴 항목 이동이 자연스러운가
- [ ] 선택된 항목이 시각적으로 구분되는가
- [ ] `GAME QUIT` 를 선택했을 때 적절한 안내가 나오는가

---

## Phase 2 — 게임 화면 뼈대

**목표:** 게임이 벌어지는 공간과 정보 표시 영역 구성

### 구현 내용
- 게임 화면 레이아웃 (배경 + 바닥선)
- 상단 HUD: 점수 / 잔기 / 제한시간 표시 자리 (값은 더미)
- `GAME START` 선택 시 메인 화면 → 게임 화면 전환
- ESC 키로 게임 화면 → 메인 화면 복귀

### 고객님 확인 포인트
- [ ] 메인에서 GAME START 누르면 게임 화면으로 전환되는가
- [ ] 게임 화면에서 ESC를 누르면 메인으로 돌아오는가
- [ ] HUD(점수·잔기·시간) 영역이 자리를 잡고 있는가
- [ ] 전체적인 화면 비율과 레이아웃이 적절한가

---

## Phase 3 — 플레이어 이동

**목표:** 캐릭터가 게임 화면 안에서 좌우로 움직인다

### 구현 내용
- 플레이어 캐릭터 렌더링 (간단한 도형 또는 스프라이트)
- ← → 키로 좌우 이동
- 화면 좌우 경계에서 이동 멈춤
- 이동 속도 조정

### 고객님 확인 포인트
- [ ] 캐릭터가 화면에 보이는가
- [ ] ← → 키로 부드럽게 이동하는가
- [ ] 화면 끝에서 벽에 막히는가
- [ ] 이동 속도가 너무 빠르거나 느리지 않은가

---

## Phase 4 — 와이어 발사

**목표:** Space 키로 와이어를 위로 발사한다

### 구현 내용
- Space 키로 와이어 발사
- 와이어가 플레이어 위치에서 천장까지 올라가는 동작
- 천장에 닿으면 와이어 소멸
- 발사 중 재발사 불가 (1발 제한)

### 고객님 확인 포인트
- [ ] Space 키로 와이어가 발사되는가
- [ ] 와이어가 천장까지 올라갔다가 사라지는가
- [ ] 와이어가 있는 동안 재발사가 막히는가
- [ ] 발사 속도와 시각적 표현이 자연스러운가

---

## Phase 5 — 풍선 물리

**목표:** 풍선이 화면 안에서 포물선을 그리며 튀어다닌다

### 구현 내용
- 풍선 등장 (대형 2개, 화면 상단)
- 중력 적용 + 바닥·벽 반사
- 크기별 반동 높이 및 이동 속도 차이 (클수록 높이 튀고, 작을수록 낮게 빠르게)
- 풍선과 플레이어는 아직 충돌 없음 (Phase 6에서 추가)

### 고객님 확인 포인트
- [ ] 풍선이 포물선 궤도로 자연스럽게 튀는가
- [ ] 벽과 바닥에서 반사가 자연스러운가
- [ ] 풍선 크기가 눈에 띄게 구분되는가
- [ ] 전반적인 물리 느낌이 게임다운가

---

## Phase 6 — 충돌 판정

**목표:** 와이어로 풍선을 터뜨리고, 풍선에 닿으면 미스가 난다

### 구현 내용
- 와이어-풍선 충돌 시 풍선 분열 (대→중→소→극소→소멸, 4단계)
- 분열 시 좌우 2개로 나뉘어 튀어오름
- 플레이어-풍선 충돌 시 미스 처리 (캐릭터 깜빡임 연출)
- 잔기 1 감소 후 스테이지 재시작

### 고객님 확인 포인트
- [ ] 와이어로 풍선을 맞히면 2개로 쪼개지는가
- [ ] 4단계 분열 끝에 풍선이 완전히 사라지는가
- [ ] 풍선에 닿으면 미스 처리가 되는가
- [ ] 분열된 풍선들의 움직임이 자연스러운가

---

## Phase 7 — 게임 규칙

**목표:** 시작 → 클리어 → 미스 → 게임오버까지 한 사이클이 완성된다

### 구현 내용
- 제한 시간 카운트다운 (HUD 반영)
- 시간 초과 시 미스 처리
- 잔기 UI 실제 연동 (초기 잔기 3개)
- 잔기 소진 시 게임오버 화면 + 메인 복귀
- 모든 풍선 제거 시 스테이지 클리어 판정

### 고객님 확인 포인트
- [ ] 제한 시간이 줄어들다가 0이 되면 미스가 나는가
- [ ] 잔기가 화면에 정확히 표시되고 줄어드는가
- [ ] 잔기를 모두 잃으면 게임오버 화면이 나오는가
- [ ] 풍선을 다 터뜨리면 클리어 처리가 되는가

---

## Phase 8 — 점수 시스템

**목표:** 풍선을 터뜨릴 때마다 점수가 쌓인다

### 구현 내용
- 풍선 크기별 점수 (극소 100 / 소 200 / 중 300 / 대 500)
- 스테이지 클리어 보너스 (남은 시간 × 10점)
- HUD 점수 실시간 반영

### 고객님 확인 포인트
- [ ] 풍선을 터뜨릴 때마다 점수가 올라가는가
- [ ] 큰 풍선보다 작은 풍선을 터뜨릴 때 점수가 더 적은가
- [ ] 클리어 시 보너스 점수가 추가되는가

---

## Phase 9 — Mission 1 스테이지 구성

**목표:** 1-1 → 1-2 → 1-3 순서로 플레이 가능한 미션 흐름 완성

### 구현 내용
- 스테이지별 풍선 초기 배치 정의
  - 1-1: 대형 2개 / 1-2: 대형 1 + 중형 2 / 1-3: 대형 2 + 중형 1 + 소형 2
- 스테이지 번호 표시 (예: STAGE 1-1)
- 스테이지 클리어 후 다음 스테이지로 전환 연출
- 1-3 클리어 시 Mission 1 완료 화면

### 고객님 확인 포인트
- [ ] 1-1 → 1-2 → 1-3 순서로 자연스럽게 이어지는가
- [ ] 스테이지마다 풍선 배치가 다른가
- [ ] 1-1은 쉽고 1-3으로 갈수록 어려워지는 느낌인가
- [ ] Mission 1 클리어 화면이 나오는가

---

## Phase 10 — 아이템

**목표:** 아이템이 등장하고 효과가 적용된다

### 구현 내용
- 풍선 파괴 시 확률로 아이템 드롭
- 시계: 일정 시간 풍선 정지
- 배리어: 충돌 1회 무적
- 1UP: 잔기 +1
- 아이템 일정 시간 후 자동 소멸

### 고객님 확인 포인트
- [ ] 아이템이 풍선 파괴 후 가끔 나오는가
- [ ] 시계를 먹으면 풍선이 멈추는가
- [ ] 배리어를 먹으면 한 번 살아나는가
- [ ] 1UP을 먹으면 잔기가 늘어나는가
- [ ] 아이템 효과가 시각적으로 명확하게 표현되는가

---

## Phase 11 — 비주얼 연출

**목표:** 게임 분위기를 살리는 배경과 연출 추가

### 구현 내용
- 후지산 테마 배경 (CSS 또는 이미지)
- 스테이지 클리어 연출 (플래시 또는 텍스트 애니메이션)
- 미스 연출 (캐릭터 소멸 효과)
- 풍선 파괴 시 터짐 이펙트

### 고객님 확인 포인트
- [ ] 배경이 게임 분위기와 어울리는가
- [ ] 클리어/미스 순간에 시각적 피드백이 명확한가
- [ ] 전반적으로 아케이드 게임 느낌이 나는가

---

## Phase 12 — Polish

**목표:** 완성도를 높이고 전체를 다듬는다

### 구현 내용
- 효과음 (풍선 터짐 / 클리어 / 미스 / 아이템 획득)
- HIGH SCORE 저장 및 표시 (localStorage)
- 전체 화면 전환 애니메이션 다듬기
- 최종 버그 수정 및 전체 플레이 테스트

### 고객님 확인 포인트
- [ ] 효과음이 상황에 맞게 재생되는가
- [ ] 최고 점수가 새로고침 후에도 유지되는가
- [ ] 처음 해보는 사람도 조작법을 직관적으로 알 수 있는가
- [ ] 전체 플레이 흐름이 끊김 없이 자연스러운가
