# PRD — 팡(Pang) 게임 Mission 1

## 1. 게임 개요

팡(Pang)은 1989년 Mitchell Corporation이 개발하고 Capcom이 유통한 아케이드 게임이다.  
플레이어는 작살(와이어) 무기를 사용해 화면 안에서 튀어다니는 풍선을 모두 터뜨리면 스테이지가 클리어된다.  
풍선은 맞을 때마다 더 작은 크기로 분열되며, 가장 작은 크기에서 터지면 완전히 사라진다.

---

## 2. Mission 1 배경

| 항목 | 내용 |
|------|------|
| 배경 | 일본 후지산(Mt. Fuji) |
| 분위기 | 야외 자연 배경, 초보자용 입문 스테이지 |
| 목표 | 화면 내 모든 풍선 제거 |

Mission 1은 게임의 첫 번째 구간으로, 조작법과 핵심 규칙을 자연스럽게 익히도록 설계된 튜토리얼 성격의 스테이지다.

---

## 3. 핵심 게임플레이 규칙

### 풍선 분열 구조

풍선은 4단계 크기로 구성된다.

```
대(Large) → 중(Medium) → 소(Small) → 극소(Tiny) → 소멸
```

- 대형 풍선 1개를 터뜨리면 중형 2개로 분열
- 분열은 맞은 위치 기준으로 좌우로 나뉨
- 크기가 작을수록 바닥 반동이 낮아져 피하기 어려워짐

### 이동 및 충돌

- 플레이어는 좌우로만 이동 가능 (점프 없음)
- 풍선에 닿으면 즉시 1미스 처리
- 제한 시간 내에 풍선을 모두 제거하지 못하면 실패

---

## 4. 무기 체계

| 무기 | 특징 |
|------|------|
| 와이어(기본) | 천장까지 닿는 줄 발사, 줄에 풍선이 닿으면 터짐 |
| 더블 와이어 | 와이어 2발 동시 유지 가능, 가장 범용적인 강력 무기 |
| 파워 와이어 | 천장에 붙어 퍼지는 와이어, 낮게 튀는 풍선 제압에 유리 |
| 벌칸 미사일 | 줄 없이 탄환 형태로 발사, 빠르지만 판정 짧음 |

---

## 5. 아이템

| 아이템 | 효과 |
|--------|------|
| 시계 | 풍선 일시정지 (제한시간은 계속 흐름) |
| 모래시계 | 풍선 이동속도 감소 |
| 배리어 | 풍선 충돌 1회 무적 + 닿은 풍선 제거 |
| 다이나마이트 | 모든 풍선을 즉시 최소 크기로 분열 (위험 요소) |
| 1UP | 잔기 1개 추가 |

---

## 6. Mission 1 구성 (스테이지 흐름)

| 스테이지 | 풍선 구성 | 난이도 |
|----------|-----------|--------|
| 1-1 | 대형 풍선 1~2개 | 매우 쉬움 |
| 1-2 | 대형 + 중형 혼합 | 쉬움 |
| 1-3 | 풍선 수 증가, 이동 패턴 다양화 | 보통 |

초반 스테이지는 풍선 수가 적고 이동 속도가 느려 무기 조작과 분열 패턴 파악을 연습하기에 적합하다.
